## 4. Nguyen-12 Model Provenance — Confirmed, not yet folded into main text

**Resolved:** the model that actually produced the Nguyen-12 results is **`claude-sonnet-5` at `temperature=0.25`**, via `hypatia.py`'s `get_llm_prior()` defaults — not `claude-sonnet-4-6`/`LLMConfig` as previously assumed. `n_candidates=8` is a confirmed override of `hypatia.py`'s own default of 5.

**Confirmed dead code:** neither the `LLM_MODEL` environment variable set in `exp3_nguyen12_hybrid50v_02.py` nor the `llm_model` field in `repro.yaml` is ever read anywhere in the pipeline — both are vestigial and misleading.

**Confirmed retraction:** dateless model IDs from the Claude 4.6 generation onward (including `claude-sonnet-4-6` and `claude-sonnet-5`) are fixed, pinned snapshots per Anthropic's documentation, not drifting aliases. The earlier "alias-drift" explanation for the 91.7%→100% seed-123 discrepancy is withdrawn.

**Confirmed, narrowed (not fully closed):**
- Cross-seed check (99, 123, 777, 2024) under identical parameters: 12/12 for every seed — rules out "unlucky seed" and "reduced sample size" as explanations.
- Within-seed (123) timestamp check: May 22 run disagrees with both July runs at the expression level (max |R² diff| ≈ 8.46×10⁻⁵); the two July runs (Jul 16, Jul 24) match exactly.
- Configuration migration window narrowed to **roughly Apr 23 – May 22, 2026** (smoke-test config confirmed present Apr 23; full paper-parameter config confirmed present May 22) — plausible window for an infrastructure migration (GCP/Kaggle → GitHub Actions), still unverified.
- `run_all.sh` remains the sole unverified link confirming what CI actually invokes.
- LLM sampling is confirmed server-side/unseedable at the API level, an independently verified contributing factor to run-to-run variability regardless of code path.
